Victoria Invitation — статический сайт

Структура:
- index.html
- css/style.css
- js/script.js

Web3Forms:
1. Получи Access Key на Web3Forms.
2. Открой js/script.js.
3. Найди строку:
   const WEB3FORMS_ACCESS_KEY = "YOUR_ACCESS_KEY_HERE";
4. Замени YOUR_ACCESS_KEY_HERE на свой ключ, не удаляя кавычки.

Локальный запуск:
python -m http.server 8000
Открыть: http://localhost:8000

Для GitHub Pages отдельный сервер не нужен.
